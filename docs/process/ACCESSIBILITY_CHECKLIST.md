# Accessibility checklist (NF-03, iOS)

## VoiceOver
- [ ] Every screen can be used from start to end with VoiceOver only.
- [ ] Each hourly cell is read as **one** sentence (time, condition, temperature, chance).
- [ ] Section titles ("Next 24 hours") are announced as headings.
- [ ] Removing a city works through VoiceOver's actions (the swipe action is exposed).
- [ ] Weather icons next to written conditions are hidden; standalone icons have labels.

## Text and touch
- [ ] Largest Dynamic Type size (Accessibility 5): nothing is cut off or overlaps.
- [ ] Every tappable element is at least 44 × 44 pt.

## Colour and motion
- [ ] Light, dark and Increase Contrast modes are all readable.
- [ ] Nothing is communicated by colour alone.
- [ ] With Reduce Motion on, the app still works.
