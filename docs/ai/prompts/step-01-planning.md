# Prompts — step 01: planning (iOS)

## 1. The task (human → agent)

> The Android version is finished. Start the iOS repo with the same seven steps. Reuse
> everything that is about the *product*; write fresh everything that is about the
> *platform*. Tell me if something is unclear.

## 2. What the agent proposed (and the human approved)

| Decision | Choice |
|---|---|
| Minimum iOS | 17, for `@Observable` |
| Language | Swift 6, strict concurrency |
| Layers | Targets of one local Swift package (ADR-0001) |
| DI | A hand-written composition root, as a contrast with Hilt (ADR-0004) |
| Errors | Typed throws (ADR-0006) |
| Storage | JSON files + `UserDefaults` instead of SwiftData (ADR-0007) |
| Project file | Generated by XcodeGen (ADR-0008) |
| Tests | Swift Testing; CI on GitHub's macOS runners |

## 3. Agent tasks in this step

| Task | Instruction |
|---|---|
| Shared docs | "Copy the PRD, user stories, wireframes, API contract and samples from the Android repo. Change only platform facts (min OS, touch target size, Dynamic Type)." |
| Architecture | "Write the iOS architecture with the same three layers as Android, so the two can be compared. Explain how Swift enforces the rule." |
| ADRs | "One per platform decision. Where iOS differs from Android (DI, storage, errors), say why." |
| Lessons | "Carry over what Android taught us: one source of truth for the language, directional isolates for values in RTL text." |
